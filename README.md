# Proud Mountain SMP

Modpack für Minecraft 1.21.1 (NeoForge): eine Forever World, in der die Jahreszeiten dem echten Kalender folgen (jede dauert drei Monate), mit Klimazonen, großen Kontinenten, Biomes O' Plenty, vielen Strukturen, Mobs und Bossen, Farmer's-Delight- und Let's-Do-Küche, Supplementaries und dem Copper Golem.

## Installation
1. [Prism Launcher](https://prismlauncher.org) installieren und mit dem Microsoft-Konto anmelden.
2. [`ProudMountainSMP-Prism.zip`](https://github.com/Stolzenberg/minecraft-modpack-proud-mountain-smp/raw/main/dist/ProudMountainSMP-Prism.zip) herunterladen und ins Prism-Fenster ziehen (oder *Instanz hinzufügen → Importieren*).
3. Instanz starten. Updates kommen bei jedem Start automatisch, der Server `server.proud-mountain.com` steht schon in der Serverliste.

Wer gerade online ist, wie der Server läuft und wer wie viel spielt: https://stats.proud-mountain.com
